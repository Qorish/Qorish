## 🔒 What I build in private projects

Most of my recent work is in private repositories. Here is what I've implemented across them, without the project names.

- **Full-stack web apps:** Next.js (App Router) and React with TypeScript, server components and server actions, and Tailwind for styling.
- **Authentication and access control:** sign-in with Supabase Auth, Firebase Auth and managed Better Auth (Neon Auth); route guards in middleware; per-user data scoping; row-level security policies and Firestore security rules.
- **Databases and migrations:** PostgreSQL with Supabase and Neon, Drizzle ORM schemas and versioned migrations, Firestore, and realtime updates.
- **Layered architecture:** controllers, services, DTO-to-model mappers and views with one-way imports, plus `server-only` boundaries to keep server code out of the client.
- **Third-party APIs:** server-side proxies for external APIs (GraphQL and REST) so provider logic and keys stay off the client; transactional email.
- **Payments and AI:** Stripe payments with webhooks, and server-side AI content moderation through Cloud Functions.
- **Cross-platform mobile:** a Flutter app for Android, iOS and web with location-aware features, maps, push notifications and image upload.
- **Security hygiene:** input validation, rate limiting, secrets kept in environment variables, human verification on contact forms, and reviewing my own code for security issues.
- **Quality:** unit and component tests with Jest and React Testing Library, ESLint, strict TypeScript, pre-commit hooks, and a reusable project template.
